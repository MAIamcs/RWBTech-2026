# Кейс «Модель маркетплейса: от корзины до выкупа» от команды ЛожкиНет

В данном репозитории хранится решение нашей команды

## Архитектура

Чтобы найти наши файлы, перейдите в scripts/model - наша написанная программа

scripts/model/answers - итоговые ответы на задания
scripts/model/tables_info - файлы, сделанные для анализа данных: количество пропусков, итоговое количество строк и т.д.

### Вычислительный и связывающий файлы

build.sql - основной вычислительный файл. В нём содержится алгоритм, который создаёт таблицы и вычисляет все данные для ответов

base.py - связывающий файл. Он связывет sql-команды, проверяет итоговые ответы на соответствие форматам и ответам
